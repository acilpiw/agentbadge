How it works: connect your wallet (MetaMask / Binance Wallet extension) on BNB Smart Chain. The contract checks on-chain that your address holds an Agent ID, then mints one badge. You confirm the transaction yourself in your wallet — this page never asks for a QR login, a pairing code, a seed phrase, or any approval. The claim itself is free; you only pay BNB network gas. Contract source is public on GitHub and verified on BscScan.
